# Torn Export Scout

With the release of travel 3.0 in torn I want to make a script where I can see what goods are best to export to that country that I can buy right now on the marketplace and bazaars of other players.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://torn-export-scout.lovable.app
